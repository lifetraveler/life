# 切片 3：搜索 + 归档

## 目标
在切片 2 基础上，实现跨标题、内容、标签名的本地搜索，以及 Item 的归档/取消归档。
本切片结束时不新增 schema，不新增 migration。

## 允许修改/新增的范围
- src/data/：Repository 实现新增 searchItems、archiveItem、unarchiveItem、listArchivedItems
- src/domain/：搜索关键词规范化与 LIKE 转义函数
- src/app/：列表页增加搜索输入；列表项增加“归档”操作；增加“已归档”入口与列表
- src/ui/：搜索框、空状态组件（如需要）

## 禁止修改/实现
- 不新增 schema 字段/表，不新增 migration
- 不引入 FTS5、不引入全文索引库
- 不实现搜索历史、搜索高亮、相关性排序
- 不实现今日/本周视图、提醒、ICS、系统日历、小组件
- 不引入新状态库
- 不修改切片 1/2 已发布的 migration step
- 不删除或修改 WatermelonDB 装饰器与构建配置

## 实现要求
1. searchItems 严格按 AGENTS.md 4.9 分步实现，禁止尝试单条跨表 OR 查询。
2. 关键词先 trim；空字符串或纯空白返回 []。
3. LIKE 转义：`%`、`_`、`\` 必须转义；写一个纯函数并配单元测试。
4. 搜索输入做 300ms 防抖；请求返回顺序错乱时以最后一次输入为准。
5. 列表项展示“归档”操作；归档后从默认列表消失，出现在“已归档”列表；可取消归档。
6. 归档不删除标签关系；取消归档后标签 chip 仍正确显示。
7. 新增文件不得出现 `any` / `as any`；UI 不得直接 import WatermelonDB database/model。

## 验收标准（逐条执行并报告）
1. `npx tsc --noEmit` 零错误。
2. `npx expo-doctor` 无阻塞性错误。
3. `npx jest --runInBand` 通过，至少包含 LIKE 转义函数与空关键词的单元测试。
4. Android 真机 development build 覆盖安装，确认切片 1/2 数据仍在，且未触发 migration。
5. 手动步骤（预置数据：标题“周会纪要”打标签“工作”；标题“买菜”打标签“生活”；内容含“周会”的另一条无标签）：
   a. 搜索“周会”，应命中标题命中项和内容命中项，按 updatedAt 降序；
   b. 搜索“工作”，应只命中标签为“工作”的条目；
   c. 搜索“%”，不应报错、不应返回全部数据；
   d. 搜索纯空格，返回空结果，不闪回全部列表；
   e. 归档“买菜”，默认列表消失，“已归档”列表出现；
   f. 取消归档“买菜”，默认列表恢复，标签“生活”仍显示；
   g. 杀掉进程重开，归档状态与标签关系均保留。
6. 代码检查：无 `any`；UI 未直连数据库；无新增 migration。
